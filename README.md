# RAB Mathematical Checker

Aplikasi lokal untuk mengecek kesalahan perhitungan pada file Excel RAB/Quotation.

## Fitur

- ✅ Cek perkalian Qty × Unit Price = Total
- ✅ Cek Subtotal sesuai jumlah item
- ✅ Cek PPN 11% sesuai
- ✅ Cek Grand Total sesuai
- ✅ Export laporan ke Excel
- ✅ Cek multiple sheet

## Cara Pakai

1. Upload file Excel RAB
2. Pilih sheet (atau semua sheet)
3. Klik "START CHECK"
4. Lihat hasil pemeriksaan

## Tech Stack

- Python 3.x
- Streamlit
- Pandas
- OpenPyXL
